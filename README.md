## Ringkasan Bab (Chapter Summary)

### [Chapter 1: Exploratory Data Analysis](./PracticalStatisticsChapter1.ipynb)
Membahas langkah awal penting dalam pemahaman data, mencakup estimasi pemusatan (*location*: mean, trimmed mean, median), penyebaran (*variability*: variansi, standar deviasi, IQR, MAD), eksplorasi distribusi data melalui boxplot dan histogram/density plot, serta korelasi dan analisis multivariabel (hexagonal binning, tabel kontingensi).

### [Chapter 2: Data and Sampling Distributions](./PracticalStatisticsChapter2.ipynb)
Membahas prinsip *sampling* acak, bias seleksi, distribusi sampling, Central Limit Theorem (CLT), metode *bootstrap resampling* untuk mengestimasi *standard error*, interval kepercayaan (*confidence intervals*), serta berbagai distribusi probabilitas penting (Normal, QQ-Plot, t-Student, Binomial, Chi-Square, Poisson, Weibull).

### [Chapter 3: Statistical Experiments and Significance Testing](./PracticalStatisticsChapter3.ipynb)
Membahas rancangan eksperimen statistik termasuk A/B testing, pengujian hipotesis (Null vs Alternative), uji permutasi (*permutation test*), interpretasi *p-value* dan tingkat signifikansi alpha, t-test, ANOVA untuk komparasi multikelompok, serta algoritma Multi-Arm Bandit.

### [Chapter 4: Regression and Prediction](./PracticalStatisticsChapter4.ipynb)
Membahas pemodelan regresi linier sederhana dan berganda, estimasi koefisien dengan metode Ordinary Least Squares (OLS), metrik evaluasi model (RMSE, R-squared), seleksi variabel dan stepwise regression (AIC), penanganan variabel kategorikal (*dummy variables*), serta diagnostik regresi (outlier, heteroskedastisitas, multikolinearitas).
